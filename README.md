# 📋 小红书管家 — 浏览器插件

一款专为小红书用户设计的文章管理浏览器插件，支持批量设置状态、收藏标记、数据导出和搜索筛选。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📄 **自动保存** | 浏览小红书时自动保存文章到本地存储 |
| 🏷️ **状态管理** | 自定义状态标签（未读/正在看/已看完/收藏/归档） |
| ✅ **批量操作** | 批量更新状态、批量删除、批量导出 |
| 📥 **数据导出** | 支持 CSV（Excel 可打开）和 JSON 格式 |
| 🔍 **搜索筛选** | 按状态筛选、按标题/作者搜索 |
| 🎨 **状态徽章** | 在文章卡片上直观显示状态标签 |
| ⚙️ **高度可定制** | 自定义状态名称、颜色和图标 |

## 📦 安装方法

### Chrome / Edge 浏览器

1. 打开浏览器，进入扩展管理页面：
   - **Chrome**: 地址栏输入 `chrome://extensions/`
   - **Edge**: 地址栏输入 `edge://extensions/`
2. 打开右上角的 **"开发者模式"**
3. 点击 **"加载已解压的扩展程序"**
4. 选择本项目的根文件夹 `xhstool/`
5. 完成安装！🎉

## 🚀 使用指南

### 浏览时自动保存
- 打开 www.xiaohongshu.com，插件会自动扫描文章卡片
- 已保存的文章会显示状态徽章（如果开启了该功能）

### 批量选择模式
1. 点击插件图标打开弹出窗口
2. 在文章列表中勾选需要操作的文章
3. 使用批量操作栏设置状态、导出或删除

### 自定义状态
1. 右键插件图标 → "选项" 进入设置
2. 进入 **状态管理** 标签页
3. 可添加、编辑、删除状态标签
4. 支持自定义名称、颜色和图标

## 🛠 技术栈

- **Manifest V3** — 最新 Chrome 扩展规范
- **原生 JavaScript** — 无框架依赖，轻量高效
- **chrome.storage.local** — 本地数据持久化
- **MutationObserver** — 动态内容检测
- **Content Script** — 页面注入和交互

## 📄 数据格式

导出的 CSV 包含以下字段：
- 标题、作者、链接、状态、收藏时间、更新时间、备注

## ⚠️ 注意事项

- 数据存储在浏览器本地，清除浏览器数据会导致文章丢失
- 建议定期导出数据备份
- 插件仅在 `www.xiaohongshu.com` 域名下生效
