📋 小红书管家 — 安装指南

支持 Chrome 和 Edge 浏览器 · 安装只需 1 分钟

🌐 在 Chrome 中安装

方法一：从 Chrome 网上应用商店安装（推荐）

1 打开 Chrome 网上应用商店
点击下方按钮，或手动访问 Chrome 网上应用商店搜索"小红书管家"。

🌐 在 Chrome 网上应用商店查看

2 点击"添加到 Chrome"
在商品详情页中，点击右上角的 "添加到 Chrome" 按钮。

🖼️ 此处展示商店页面的"添加到 Chrome"按钮截图

3 确认权限
弹出对话框会显示插件所需的权限，点击 "添加扩展程序" 确认。

4 安装完成 🎉
安装成功后，浏览器右上角工具栏会出现 📋 图标。点击图标即可开始使用！

方法二：手动加载（开发者模式）

如果你从 GitHub 下载了源码，可以手动加载未打包的扩展：

1 在 Chrome 地址栏输入 chrome://extensions/

2 打开右上角的 "开发者模式" 开关

3 点击 "加载已解压的扩展程序"，选择项目文件夹即可

🧭 在 Microsoft Edge 中安装

方法一：从 Edge 扩展商店安装（推荐）

1 打开 Edge 扩展商店
点击下方按钮，或手动访问 Edge 扩展商店搜索"小红书管家"。

🧭 在 Edge 扩展商店查看

2 点击"获取"
在商品详情页中，点击 "获取" 按钮。

3 确认添加
弹出窗口中点击 "添加扩展" 确认安装。

4 安装完成 🎉
安装成功后，浏览器右上角工具栏会出现 📋 图标。点击图标即可开始使用！

方法二：手动加载（开发者模式）

如果你从 GitHub 下载了源码，可以手动加载：

1 在 Edge 地址栏输入 edge://extensions/

2 打开左下角的 "开发人员模式" 开关

3 点击 "加载解压缩的扩展"，选择项目文件夹即可

💡 使用提示

📌 固定到工具栏
安装后，点击浏览器右上角的拼图图标（扩展管理），找到"小红书管家"旁边的 📌 图钉，将其固定到工具栏方便快速访问。

⚙️ 打开设置
右键点击工具栏的 📋 图标，选择 "选项" 进入设置页面，可自定义状态标签、导入导出数据等。

⚠️ 使用前提
本插件需要在小红书创作者后台（creator.xiaohongshu.com）的笔记管理页面中使用。请确保你已登录小红书账号并拥有创作者权限。

❓ 常见问题

Q：插件无法正常工作？

A：请确保你已登录小红书创作者后台，并打开笔记管理页面（https://creator.xiaohongshu.com/new/note-manager）。尝试刷新页面或重新安装插件。

Q：数据存在哪里？安全吗？

A：所有数据仅存储在浏览器本地，不会上传到任何服务器。卸载插件或清除浏览器数据会导致数据丢失，建议定期导出备份。

Q：如何卸载？

A：在地址栏输入 chrome://extensions/（Chrome）或 edge://extensions/（Edge），找到"小红书管家"，点击"移除"即可。
