📋 小红书管家

浏览器插件安装指南 · 支持 Chrome 和 Edge

🌐 Google Chrome Chrome

1
打开 Chrome 网上应用商店
在浏览器地址栏输入 chrome://webstore 并回车。
2
搜索"小红书管家"
在商店搜索框中输入 "小红书管家"，找到本插件。
💡 也可直接访问：https://chromewebstore.google.com/detail/agmhbhofmbcidcmokocnpeicegnjhjee
3
点击"添加到 Chrome"
在商品详情页中，点击右上角的 "添加到 Chrome" 蓝色按钮。
4
确认权限并完成安装
弹出窗口中会显示插件所需的权限，点击 "添加扩展程序" 确认。
✅ 安装成功后，右上角工具栏会出现 📋 图标

🧭 Microsoft Edge Edge

1
打开 Chrome 网上应用商店
Edge 基于 Chromium 内核，完全兼容 Chrome 扩展。
在地址栏输入下方网址并回车：
https://chromewebstore.google.com/detail/agmhbhofmbcidcmokocnpeicegnjhjee
2
点击"获取"
在页面中点击 "获取" 按钮，弹出窗口中点击 "添加扩展" 确认安装。
✅ 安装成功后，右上角工具栏会出现 📋 图标

💡 安装后使用指引

📌 第一步：固定到工具栏
点击浏览器右上角的 🧩 拼图图标（扩展管理），在列表中找到"小红书管家"，点击旁边的 📌 图钉将其固定到工具栏。
⚙️ 第二步：打开设置
右键点击工具栏的 📋 图标，选择 "选项" 进入设置页面。可自定义状态标签、导入导出数据。
🚀 第三步：开始使用
打开 小红书创作者后台 → 笔记管理 页面，插件自动生效。可批量设置权限、置顶、删除笔记。
⚠️ 使用前提
需要在小红书创作者后台（creator.xiaohongshu.com）的笔记管理页面中使用。请确保已登录小红书账号并拥有创作者权限。

❓ 常见问题

Q：插件安装后没有反应？
请确保已登录小红书创作者后台，并打开笔记管理页面（https://creator.xiaohongshu.com/new/note-manager）。尝试刷新页面或重新安装。
Q：数据存在哪里？安全吗？
所有数据仅存储在浏览器本地，不会上传到任何服务器。卸载插件或清除浏览器数据会导致数据丢失，建议定期导出备份。
Q：如何卸载插件？
地址栏输入 chrome://extensions/（Chrome）或 edge://extensions/（Edge），找到"小红书管家"，点击 "移除"。
